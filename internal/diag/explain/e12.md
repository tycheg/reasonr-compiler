# E12xx — external systems and fakes

## E1201

The parentheses of an external system hold the role it answers with: the system calls public model commands like any API client (RFC §18). There is exactly one role, declared with role. The compiler uses it to check that the system can answer, and the system's fake calls commands with it.

```rr
role matching

external(matchng) Matching
  request findDriver(orderId Order.Id)

aggregate Order
  id uuid

  command(matching) DriverFound()
    found()

  command place()
    Matching.findDriver(orderId: id)

  event found()
```

```rr
role matching

external(matching) Matching
  request findDriver(orderId Order.Id)

aggregate Order
  id uuid

  command(matching) DriverFound()
    found()

  command place()
    Matching.findDriver(orderId: id)

  event found()
```

## E1202

The timeout parameter of an external request is special: it is a model timer. The model schedules a timer and passes it to the request; the timer's time is the delivery deadline, and its command is the model's reaction to "no answer". The engine stops delivering the request once the timer has fired or been deleted. So the parameter type is Timer.Id or Timer.Id?.

```rr
external Matching
  request findDriver(orderId Order.Id, timeout duration)

aggregate Order
  id uuid

  command place()
    Matching.findDriver(orderId: id, timeout: 60s)
    placed()

  command searchTimedOut()
    placed()

  event placed()
```

```rr
external Matching
  request findDriver(orderId Order.Id, timeout Timer.Id)

aggregate Order
  id uuid

  command place()
    let timer = schedule(at: now + 60s, run: searchTimedOut())
    Matching.findDriver(orderId: id, timeout: timer)
    placed()

  command searchTimedOut()
    placed()

  event placed()
```

## E1203

An external request's deadline used to be written after the parameters (timeout 30s) and lived apart from the model's reaction to a missing answer. Now the deadline is a model timer: declare a parameter timeout Timer.Id, schedule a timer and pass it to the request. The compiler fix removes the old clause and adds the parameter; request calls must be given a timer by hand.

```rr
external Matching
  request findDriver(orderId Order.Id) timeout 30s

aggregate Order
  id uuid

  command place()
    Matching.findDriver(orderId: id)
    placed()

  command searchTimedOut()
    placed()

  event placed()
```

```rr
external Matching
  request findDriver(orderId Order.Id, timeout Timer.Id)

aggregate Order
  id uuid

  command place()
    let timer = schedule(at: now + 30s, run: searchTimedOut())
    Matching.findDriver(orderId: id, timeout: timer)
    placed()

  command searchTimedOut()
    placed()

  event placed()
```

## E1204

A fake of an external system is test code: it is built into the test program only (reasonrd test, reasonrd --test), and the production build does not see it. So fake is written only in *.fake.rr files of the base module — not in model files, tests or extensions.

```rr
role matching

external(matching) Matching
  request findDriver(orderId Order.Id)

aggregate Order
  id uuid
  driver int

  command place()
    Matching.findDriver(orderId: id)
    placed()

  command(matching) DriverFound(driverId int)
    found(driverId: driverId)

  event placed()

  event found(driverId int)
    driver = driverId

fake Matching
  driver int

  command Setup(driverId int)
    configured(driverId: driverId)

  event configured(driverId int)
    driver = driverId

  request findDriver(orderId Order.Id)
    [orderId].DriverFound(driverId: driver)
```

## E1209

A fake behaves like an external system: it sees only the request arguments and its own fields, and talks to the model by calling its public commands. Reading entities and projections, ?., model queries, external requests, projection updates, forget, id and personal are not available in a fake: a fake that knows more than the real system would hide model bugs.

```rr
role matching

external(matching) Matching
  request findDriver(orderId Order.Id)

aggregate Order
  id uuid
  driver int

  command place()
    Matching.findDriver(orderId: id)
    placed()

  command(matching) DriverFound(driverId int)
    found(driverId: driverId)

  event placed()

  event found(driverId int)
    driver = driverId

# file: m.fake.rr
fake Matching
  driver int

  command Setup(driverId int)
    configured(driverId: driverId)

  event configured(driverId int)
    driver = driverId

  request findDriver(orderId Order.Id)
    if [orderId]
      [orderId].DriverFound(driverId: driver)
```

## E1210

Fake commands set the fake up in a test: the test itself calls them, not a user or a role. So a step with a fake command is written without as.

```rr
role matching

external(matching) Matching
  request findDriver(orderId Order.Id)

aggregate Order
  id uuid
  driver int

  command(matching) Place()
    Matching.findDriver(orderId: id)
    placed()

  command(matching) DriverFound(driverId int)
    found(driverId: driverId)

  event placed()

  event found(driverId int)
    driver = driverId

# file: m.fake.rr
fake Matching
  driver int

  command Setup(driverId int)
    configured(driverId: driverId)

  event configured(driverId int)
    driver = driverId

  request findDriver(orderId Order.Id)
    [orderId].DriverFound(driverId: driver)

# file: m.test.rr
test "Fake answers with a driver"
  let o1 = new Order.Id
  given
    Matching.Setup(driverId: 7) as matching
  when
    [o1].Place() as matching
  then
    request Matching.findDriver(orderId: o1)
```
