# E00xx — lexis and syntax

## E0001

The text contains a character that is not part of the language. Logical operators are words (and, or, not), not &&, || or !; semicolons are not used — statements are separated by line breaks.

```rr
aggregate Account
  id uuid
  frozen bool
  balance decimal

  command check()
    if frozen && balance < 0
      return
```

```rr
aggregate Account
  id uuid
  frozen bool
  balance decimal

  command check()
    if frozen and balance < 0
      return
```

## E0002

Indentation uses spaces only: a block is indented by 2 spaces. A tab at the start of a line is an error because editors display its width differently.

```rr
aggregate Account
	id uuid
```

```rr
aggregate Account
  id uuid
```

## E0003

A nested block is indented exactly 2 spaces more than its parent. This keeps all models uniform and makes nesting obvious.

```rr
aggregate Account
    id uuid
```

```rr
aggregate Account
  id uuid
```

## E0004

A line dedents to a level that no enclosing block uses. When leaving a nested block, the indentation must match one of the outer levels.

```rr
aggregate Account
  id uuid
  frozen bool

  command check()
    if frozen
      return
   return
```

```rr
aggregate Account
  id uuid
  frozen bool

  command check()
    if frozen
      return
    return
```

## E0005

A string literal is not closed before the end of the line. Strings are single-line; write a line break inside a string as \n.

```rr
aggregate Account
  id uuid
  note string = "no end
```

```rr
aggregate Account
  id uuid
  note string = "with an end"
```

## E0006

A date or timestamp literal has the wrong format. A date is date"YYYY-MM-DD", a timestamp uses RFC 3339 with a time zone: timestamp"2026-10-02T12:00:00Z".

```rr
aggregate Promo
  id uuid
  startsAt timestamp = timestamp"2026-10-02 12:00"
```

```rr
aggregate Promo
  id uuid
  startsAt timestamp = timestamp"2026-10-02T12:00:00Z"
```

## E0007

A number is malformed: leading zeros, an underscore not between digits, a dot without a fraction, or an unknown duration suffix. Durations are integers with ms, s, m, h or d: 90m instead of 1.5h.

```rr
aggregate Offer
  id uuid
  ttl duration = 1.5h
```

```rr
aggregate Offer
  id uuid
  ttl duration = 90m
```

## E0008

Braces in an interpolated string are wrong: an empty {}, an unpaired brace, or a nested string inside {…}. To insert a literal brace, double it: {{ or }}.

```rr
role admin

aggregate Account
  id uuid
  balance decimal

  command(admin) Warn()
    warned(text: "balance {}")

  notification warned(text string)
```

```rr
role admin

aggregate Account
  id uuid
  balance decimal

  command(admin) Warn()
    warned(text: "balance {balance}")

  notification warned(text string)
```

## E0009

A string contains an unknown escape sequence. Allowed are \" (quote), \\ (backslash), \n, \t and \u{code} with a Unicode code point.

```rr
aggregate Account
  id uuid
  note string = "C:\temp\q"
```

```rr
aggregate Account
  id uuid
  note string = "C:\\temp\\q"
```

## E0010

Arguments of commands, events, errors, notifications and constructors are passed by name: name: value. Calls then read without looking at the declaration and do not break when parameters are reordered. Only built-in functions are called positionally: round(x, 2), decimal(n).

```rr
aggregate Account
  id uuid
  balance decimal

  command deposit(amount decimal)
    deposited(amount)

  event deposited(amount decimal)
    balance = balance + amount
```

```rr
aggregate Account
  id uuid
  balance decimal

  command deposit(amount decimal)
    deposited(amount: amount)

  event deposited(amount decimal)
    balance = balance + amount
```

## E0011

A line must be a statement: a call (command, event, error, notification, projection upsert), an assignment or a keyword construct (let, if, for, return…). An expression whose result goes nowhere is an error.

```rr
aggregate Account
  id uuid
  balance decimal

  command touch()
    balance + 1
```

```rr
aggregate Account
  id uuid
  balance decimal

  command touch()
    let next = balance + 1
    touched(next: next)

  event touched(next decimal)
    balance = next
```

## E0012

The parser expected one construct and found another. The message says what was expected and what was found; usually it is a missing parenthesis, a missing colon in a named argument, or an extra word in a declaration.

```rr
aggregate Account
  id uuid
  balance decimal

  command deposit(amount decimal
    return
```

```rr
aggregate Account
  id uuid
  balance decimal

  command deposit(amount decimal)
    return
```

## E0014

Only a let variable name or, inside an event, a field name may appear left of =. There is no assignment to value-object fields (price.amount = …) or collection elements: values and collections are immutable, build a new value instead.

```rr
value Money
  amount decimal

aggregate Order
  id uuid
  price Money

  event discounted(amount decimal)
    price.amount = amount
```

```rr
value Money
  amount decimal

aggregate Order
  id uuid
  price Money

  event discounted(amount decimal)
    price = Money(amount: amount)
```

## E0015

A line is indented although the previous line does not open a nested block. Nested blocks follow declarations with a body and the statements if, else, for, while, given, when, then.

```rr
aggregate Account
  id uuid
  balance decimal

  command touch()
    touched()
      return

  event touched()
```

```rr
aggregate Account
  id uuid
  balance decimal

  command touch()
    touched()
    return

  event touched()
```

## E0016

A command, query, rule, reaction, branch or loop header must be followed by a body indented by 2 spaces. There are no empty bodies: write return if there is nothing to do.

```rr
aggregate Account
  id uuid

  command touch()
```

```rr
aggregate Account
  id uuid

  command touch()
    return
```

## E0017

Comparisons cannot be chained as in mathematics (0 < x < 10): such chains mean different things in different languages. Join two comparisons with and.

```rr
value Percent
  value100 int
  check 0 <= value100 <= 100
```

```rr
value Percent
  value100 int
  check 0 <= value100 and value100 <= 100
```

## E0018

A search section (where, sort, page, limit, select) or a test section (given, when, then) appears twice. Merge them: several where conditions are joined with and.

```rr
value Row
  title string

aggregate Item
  id uuid
  kind string
  title string

  index byKind(kind, title)

  query Find(wanted string) list<Row>
    return [Item]
      where kind == wanted
      where title == "x"
      limit 10
      select Row(title: title)
```

```rr
value Row
  title string

aggregate Item
  id uuid
  kind string
  title string

  index byKind(kind, title)

  query Find(wanted string) list<Row>
    return [Item]
      where kind == wanted and title == "x"
      limit 10
      select Row(title: title)
```

## E0020

Test sections come in a fixed order: let, then given, when and then. Every test then reads the same way: setup, action, expectations.

```rr
aggregate Account
  id uuid

  command(admin) Open()
    opened()

  event opened()

role admin

test "Account opens"
  let a = new Account.Id
  when
    [a].Open() as admin
  given
    time offset +1s
```

```rr
aggregate Account
  id uuid

  command(admin) Open()
    opened()

  event opened()

role admin

test "Account opens"
  let a = new Account.Id
  given
    time offset +1s
  when
    [a].Open() as admin
```

## E0021

Search sections come in a fixed order: where, sort, page or limit, select. It matches the execution order: filter, sort, page, shape the result.

```rr
value Row
  title string

aggregate Item
  id uuid
  kind string
  title string

  index byKind(kind, title)

  query Find() list<Row>
    return [Item]
      sort title
      where kind == "x"
      limit 10
      select Row(title: title)
```

```rr
value Row
  title string

aggregate Item
  id uuid
  kind string
  title string

  index byKind(kind, title)

  query Find() list<Row>
    return [Item]
      where kind == "x"
      sort title
      limit 10
      select Row(title: title)
```
