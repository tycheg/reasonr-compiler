# E07xx — UI: apps, screens, primitives, texts

## E0701

The primitive declaration is invalid. A type variable is inferred from the place in the layout, so it must appear in binds or in a parameter type; binds and children are written once; parts bind the fields of a value, and params and inputs belong only to primitives that bind a query and a command; names of parameters, parts and events do not repeat.

```rr
primitive Badge<T>
  binds field string
```

```rr
primitive Badge<T>
  binds field T
```

## E0702

The binding of the line does not fit the primitive. A primitive declares what it is placed on: Table on a query returning a page, Card on a query returning a value, Form and Edit on a command, Link on a screen, Text and TextInput on a field (the field name goes before the primitive), a layout on nothing.

```rr
value Row
  orderId Order.Id

actor Customer
  id uuid

aggregate Order
  id uuid
  customer Customer.Id?

  index byCustomer(customer)

  query(Customer) Mine(pageReq PageRequest) page<Row>
    return [Order]
      where customer == me
      page pageReq
      select Row(orderId: id)

app(Customer) Shop
  Menu
    MyOrders

screen MyOrders
  Card Order.Mine
```

## E0703

The binding refers to something other than a public method or a screen. Only public commands and queries (uppercase) of entities, actors and projections are available in the UI; private ones are called by other commands and timers. Link and on transitions lead to declared screens.

```rr
actor Customer
  id uuid

  command(self) Touch()
    touch()

  command touch()
    return

app(Customer) Shop
  Menu
    Home

screen Home
  Button Customer.touch
```

## E0705

A command target without [x] is taken by type: the only X.Id value in the nearest scope. Here there are several, and the compiler does not guess which one is the target. Set the target explicitly: [orderId].Cancel.

```rr

  orderId Order.Id
  parentId Order.Id

actor Customer
  id uuid

aggregate Order
  id uuid
  customer Customer.Id?

  index byCustomer(customer)

  command(customer) Cancel()
    return

  query(Customer) Mine(pageReq PageRequest) page<Row>
    return [Order]
      where customer == me
      page pageReq
      select Row(orderId: id, parentId: id)

app(Customer) Shop
  Menu
    MyOrders

screen MyOrders
  Table Order.Mine
    RowActions
      Button Order.Cancel
```

## E0706

An argument without an explicit binding is taken from the value of the same name in the nearest scope — a screen parameter, a data field or a row. Here the value has another type. Same names with different types are almost always a mistake: fix the type or bind the argument explicitly (orderId: expression).

```rr
value OrderView
  title string

actor Customer
  id uuid

aggregate Order
  id uuid
  title string

  query(Customer) View(orderId Order.Id) OrderView
    let o = [orderId]
    if o is none
      return OrderView(title: "")
    return OrderView(title: o.title)

app(Customer) Shop
  Menu
    Home

screen Home
  Toolbar

screen Detail(orderId string)
  Card Order.View
```

## E0707

A field or input has no default primitive. Nobody types an id by hand: it needs a picker, e.g. default Customer.Id EntityPicker(search: Customer.Find) at module or app level. For types without a standard primitive (map) declare a default or a primitive of your own.

```rr
role admin

actor Customer
  id uuid

aggregate Order
  id uuid

  command(admin) Assign(customerId Customer.Id)
    return

app(admin) Back
  Menu
    Assigns

screen Assigns
  Form [new Order.Id].Assign
```

```rr
role admin

value CustomerRow
  customerId Customer.Id
  name string

actor Customer
  id uuid
  name string

  index byName(name)

  query(admin) Find(text string) list<CustomerRow>
    return [Customer]
      where name == text
      limit 10
      select CustomerRow(customerId: id, name: name)

aggregate Order
  id uuid

  command(admin) Assign(customerId Customer.Id)
    return

default Customer.Id EntityPicker(search: Customer.Find)

app(admin) Back
  Menu
    Assigns

screen Assigns
  Form [new Order.Id].Assign
```

## E0708

The argument has no source: it is not passed in the binding, the scope has no value of that name, and there is nowhere to enter it. Button shows no fields — a command with inputs needs Edit, Form or Confirm; a primitive's query parameter binds its arguments to the values the primitive passes (phoneNumber: text).

```rr
actor Customer
  id uuid
  name string?

  command(self) Rename(newName string)
    renamed(newName: newName)

  event renamed(newName string)
    name = newName

app(Customer) Shop
  Menu
    Home

screen Home
  Button Customer.Rename
```

## E0712

default sets the default primitive for a type: a field display (binds field) or input (binds input) primitive that takes this type. Here the primitive does not exist, neither displays nor enters a field, does not take the type, or a default for this type and role is already declared at this level.

```rr
default string Tag
```

```rr
default string Text
```

## E0713

A text key refers to a model name or a layout node: Type, Type.member, Type.Method.parameter, Enum.value, App, Screen, Screen:binding[#n]. There is no such name or node, or a text with this key in this language is already given (by a layout string or in texts).

```rr
    return

texts de
  Customer.Tuch "Check in"
```

## E0714

A placeholder {name} in a text shows a parameter of an error or a notification: "Cannot cancel an order with status {currentStatus}". Here the error or notification has no such parameter, {…} holds something other than a name, or the placeholder is in a text that has no parameters.

```rr
aggregate Order
  id uuid

  error cannotCancel(currentStatus string)

texts de
  Order.cannotCancel "Cannot cancel an order in status {status}"
```
