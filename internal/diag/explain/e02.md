# E02xx — types

## E0201

The name is not declared as a variable, parameter or field, nor is it a built-in value. Check the spelling: the compiler suggests the closest name, and for an enum value — how to write it in full.

```rr
aggregate Account
  id uuid
  balance decimal

  command touch()
    if balanse < 0
      return
```

```rr
aggregate Account
  id uuid
  balance decimal

  command touch()
    if balance < 0
      return
```

## E0202

The value has the wrong type. There are no implicit conversions except T → T?: different number kinds, strings and ids of different entities do not mix. Convert explicitly — decimal(x), int(x), string(x) — or fix the type.

```rr
aggregate Account
  id uuid
  note string

  event noted(count int)
    note = count
```

```rr
aggregate Account
  id uuid
  note string

  event noted(count int)
    note = string(count)
```

## E0203

Required arguments are missing. A parameter is required unless it has a default (= value) or an optional type.

```rr
aggregate Account
  id uuid
  balance decimal

  command touch()
    deposited()

  event deposited(amount decimal)
    balance = balance + amount
```

```rr
aggregate Account
  id uuid
  balance decimal

  command touch()
    deposited(amount: 0)

  event deposited(amount decimal)
    balance = balance + amount
```


## E0206

A command is called by an id that may be none. Write [x]?.command(…): the call runs only if there is a value. Or check x is not none first — the type then narrows.

```rr
actor Customer
  id uuid

  command notify()
    return

aggregate Order
  id uuid
  customer Customer.Id?

  command finish()
    [customer].notify()
```

```rr
actor Customer
  id uuid

  command notify()
    return

aggregate Order
  id uuid
  customer Customer.Id?

  command finish()
    [customer]?.notify()
```

## E0207

x?.name is only needed for values that may be none. Here the value is always present — use a plain dot.

```rr
value Money
  amount decimal

aggregate Order
  id uuid
  price Money
  total decimal

  event priced()
    total = price?.amount
```

```rr
value Money
  amount decimal

aggregate Order
  id uuid
  price Money
  total decimal

  event priced()
    total = price.amount
```

## E0208

delete only removes a timer (a Timer.Id or Timer.Id? value) or a projection row ([martId]). Entities are never deleted: their lifecycle is a status field.

```rr
aggregate Order
  id uuid
  status int
  timer Timer.Id?

  command cancel()
    delete status
```

```rr
aggregate Order
  id uuid
  status int
  timer Timer.Id?

  command cancel()
    delete timer
```

## E0209

The recipient after to must be an actor id (or T?: if none, nothing is sent). A notification is received by a person or system signed in as an actor.

```rr
actor Customer
  id uuid

aggregate Order
  id uuid
  customer Customer.Id?
  status int

  command finish()
    finished() to status

  notification finished()
```

```rr
actor Customer
  id uuid

aggregate Order
  id uuid
  customer Customer.Id?
  status int

  command finish()
    finished() to customer

  notification finished()
```

## E0210

Ids (Order.Id, Timer.Id) have no default value: there are no zero ids. A field of such a type in an entity or projection must be optional — it is none until assigned.

```rr
actor Customer
  id uuid

aggregate Order
  id uuid
  customer Customer.Id
```

```rr
actor Customer
  id uuid

aggregate Order
  id uuid
  customer Customer.Id?
```

## E0211

The field type has no default value: a value with an id field, a value whose defaults break its own check, or page<T>. Make the field optional or give it = value.

```rr
value Range
  low int
  high int
  check low < high

aggregate Slot
  id uuid
  range Range
```

```rr
value Range
  low int
  high int
  check low < high

aggregate Slot
  id uuid
  range Range = Range(low: 0, high: 1)
```

## E0212

A default value is computed without running the model: literals, enum values, value constructors and arithmetic over them are allowed, but not method calls, now or entity lookups.

```rr
aggregate Account
  id uuid
  code string = "abc".upper()
```

```rr
aggregate Account
  id uuid
  code string = "ABC"
```

## E0213

The call result goes nowhere. Store it in a variable or use it; only calls without a result stand on their own line: commands, events, errors, notifications, projection upserts.

```rr
aggregate Order
  id uuid
  price decimal

  rule rate() decimal
    return 30

  command place()
    rate()
```

```rr
aggregate Order
  id uuid
  price decimal

  rule rate() decimal
    return 30

  command place()
    priced(amount: rate())

  event priced(amount decimal)
    price = amount
```

## E0214

The statement or expression is not allowed here; the message explains why: a type used as a value, calling something that is not callable, a wrong argument count for a built-in, assigning to a parameter, break outside a loop and so on.

```rr
aggregate Account
  id uuid
  balance decimal

  command touch()
    break
```

```rr
aggregate Account
  id uuid
  balance decimal

  command touch()
    return
```

## E0215

new T.Id only generates uuid and sequence ids. A string or composite (value) id is chosen by the caller: pass it as a parameter.

```rr
aggregate Shift
  id string

  command(admin) Plan()
    return

aggregate Planner
  id uuid

  command(admin) Run()
    [new Shift.Id].Plan()

role admin
```

```rr
aggregate Shift
  id string

  command(admin) Plan()
    return

aggregate Planner
  id uuid

  command(admin) Run(code Shift.Id)
    [code].Plan()

role admin
```

## E0216

Type.Id(x) only converts a projection id into the id of the entity it is based on and back: OrderMart.Id(orderId), Order.Id(martId). Ids of different entities are not convertible.

```rr
aggregate Order
  id uuid

  command place(other Customer.Id)
    OrderMart(id: OrderMart.Id(other))

actor Customer
  id uuid

projection OrderMart
  id Order.Id
```

```rr
aggregate Order
  id uuid

  command place(other Customer.Id)
    OrderMart(id: OrderMart.Id(id))

actor Customer
  id uuid

projection OrderMart
  id Order.Id
```

## E0217

In a command, [x] is a reference to another entity: its fields are not available. You can only check that it exists (if [x]) and call its command. Pass the needed data as an argument or read it in a query of its type.

```rr
actor Driver
  id uuid
  name string

aggregate Order
  id uuid
  driverName string

  command assign(driverId Driver.Id)
    let n = [driverId]?.name
    return
```

```rr
actor Driver
  id uuid
  name string

aggregate Order
  id uuid
  driverName string

  command assign(driverId Driver.Id, driver string)
    named(driver: driver)

  event named(driver string)
    driverName = driver
```

## E0218

The type cannot be inferred from the value itself: none, an empty list [] and an empty map [:] fit any type. Give the variable a type: let x Driver.Id? = none.

```rr
aggregate Order
  id uuid

  command touch()
    let tags = []
    return
```

```rr
aggregate Order
  id uuid

  command touch()
    let tags list<string> = []
    return
```

## E0219

A value of an optional type may be none, but the operation needs a value. Check it (if x is not none), use ?. or supply a fallback with ??.

```rr
aggregate Account
  id uuid
  note string?
  size int

  event measured()
    size = note.length
```

```rr
aggregate Account
  id uuid
  note string?
  size int

  event measured()
    size = note?.length ?? 0
```

## E0220

The operator does not apply to values of these types: arithmetic works on numbers of one kind, durations and time; ordering comparisons on ordered types; is none on optionals; in on collections.

```rr
aggregate Account
  id uuid
  balance decimal
  limit int

  command check()
    if balance + limit > 0
      return
```

```rr
aggregate Account
  id uuid
  balance decimal
  limit int

  command check()
    if balance + decimal(limit) > 0
      return
```

```rr
  id uuid
  price Money

    total = price.total
```

```rr
value Money
```

## E0222

`faker` (plausible random values) and `range(n)` (numbers from 0 to n−1) are tools of tests and demo scenarios (`*.test.rr`, `*.demo.rr`, RFC §27.4). In a model values come as command parameters: the command stays deterministic and can be replayed.

```rr
actor Customer
  id uuid
  name string

  command(self) SignUp()
    signedUp(customerName: faker.name())

  event signedUp(customerName string)
    name = customerName
```

```rr
actor Customer
  id uuid
  name string

  command(self) SignUp(customerName string)
    signedUp(customerName: customerName)

  event signedUp(customerName string)
    name = customerName
```
