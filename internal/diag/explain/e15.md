## E1501

A flag is declared with its creation date, a YYYY-MM-DD string with a valid date: reasonrd feature list shows the flag age from it, so rolled-out flags are removed from the code in time.

```rr
feature tips "07.11.2026"

test "Tips"
  feature tips
  when
    time offset +1s
```

```rr
feature tips "2026-11-07"

test "Tips"
  feature tips
  when
    time offset +1s
```

## E1502

Flags do not nest: inside a branch of a flag condition (including else) neither another flag nor the same flag is read. Nested flags create combinations nobody tests or rolls out. The check is lexical: calling a command that has its own flag is not nesting.

```rr
role admin

feature tips "2026-11-07"
feature bonus "2026-11-07"

aggregate Order
  id uuid
  tip int

  command(admin) LeaveTip(amount int)
    if tips
      if bonus
        tipped(amount: amount + 1)

  event tipped(amount int)
    tip = amount

test "Tips"
  feature tips, bonus
  when
    time offset +1s
```

```rr
role admin

feature tips "2026-11-07"
feature bonus "2026-11-07"

aggregate Order
  id uuid
  tip int

  command(admin) LeaveTip(amount int)
    if tips
      tipped(amount: amount)
    if bonus
      tipped(amount: 1)

  event tipped(amount int)
    tip = amount

test "Tips"
  feature tips, bonus
  when
    time offset +1s
```

## E1504

A flag is a call value: the engine computes it for the caller once per unit of work. Commands, queries, rules, on reactions and layouts read it. Events do not read flags: event replay must not depend on the rollout; pass the value as an event parameter. Value methods and invariants, default values and migrations know no caller, fakes see only request arguments, and a test enables flags with a feature line.

```rr
role admin

feature tips "2026-11-07"

aggregate Order
  id uuid
  tipped bool

  command(admin) Close()
    closed()

  event closed()
    tipped = tips

test "Tips"
  feature tips
  when
    time offset +1s
```

```rr
role admin

feature tips "2026-11-07"

aggregate Order
  id uuid
  tipped bool

  command(admin) Close()
    closed(withTips: tips)

  event closed(withTips bool)
    tipped = withTips

test "Tips"
  feature tips
  when
    time offset +1s
```

## E1506

The caller's flag set is a bit set of 256 flags. A flag is temporary: once rolled out to the whole system, it is removed from the code (reasonr feature remove).

```rr skip
feature f1 "2026-11-07"
# … 256 more flags
```

```rr skip
feature f1 "2026-11-07"
# … at most 256 flags
```

## W1501

Code under a flag is covered by tests that enable the flag with a feature line at their start; old tests check the behavior with the flag off and do not change. A flag without such a test ships to production untested.

```rr
role admin

feature tips "2026-11-07"

aggregate Order
  id uuid
  tip int

  command(admin) LeaveTip(amount int)
    if tips
      tipped(amount: amount)

  event tipped(amount int)
    tip = amount
```

```rr
role admin

feature tips "2026-11-07"

aggregate Order
  id uuid
  tip int

  command(admin) LeaveTip(amount int)
    if tips
      tipped(amount: amount)

  event tipped(amount int)
    tip = amount

test "Tips"
  feature tips
  let o1 = new Order.Id
  when
    [o1].LeaveTip(amount: 10) as admin
```
